# Xellar-Project
This repository primarily maintains code related to the Xellar project.

## ReVMAP

[ReVMAP](ReVMAP/) contains the code, frozen graph subsets, evaluation cohorts,
saved predictions, and reproduction instructions for **ReVMAP: Heterogeneous
knowledge graph learning for target-contextualized drug-action prediction**.

Start with the [ReVMAP README](ReVMAP/README.md). Software and data licensing
are documented separately in that directory.
